# 🚗 Car Market Trends Analysis using CarDekho Dataset

## 📌 Project Overview

This project analyzes the CarDekho vehicle dataset using Python and Exploratory Data Analysis (EDA) to understand used-vehicle market trends and selling-price patterns.

The analysis explores vehicle characteristics such as manufacturing year, selling price, present price, kilometres driven, fuel type, seller type, transmission and ownership.

## 🎯 Project Objective

The objective is to analyze the CarDekho dataset and identify useful patterns related to vehicle prices, depreciation, vehicle age, mileage, fuel preferences, transmission types, seller categories and ownership.

The project also examines separate vehicle segments such as cars and two-wheelers to generate meaningful market insights.

## 📊 Dataset

The dataset contains **301 vehicle records** and **9 features**:

- Car Name
- Manufacturing Year
- Selling Price
- Present Price
- Kilometres Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

The dataset is provided in Excel format as `car_data.xlsx`.

## 🛠️ Technologies Used

- **Python** – Data analysis and programming
- **Pandas** – Data loading, cleaning and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical and graphical visualization
- **Google Colab** – Notebook development and execution

## 🔍 Analysis Performed

The project includes analysis of:

- Vehicle manufacturing year distribution
- Selling price distribution
- Fuel type preferences
- Seller type distribution
- Transmission distribution
- Ownership patterns
- Kilometres driven
- Vehicle depreciation
- Vehicle age and resale price
- Frequently listed vehicle models
- Separate analysis of cars and two-wheelers
- High-value vehicle listings and market patterns

## 📈 Key Insights

The analysis helps identify patterns in used-vehicle prices and depreciation.

It also shows differences in fuel types, transmission categories, seller types and ownership patterns. Vehicle age, kilometres driven and present price are useful factors for understanding resale value.

The project further identifies popular vehicle models and compares different vehicle segments.

## 📁 Project Files

- `CarDekho_Car_Market_Analysis.ipynb` – Complete Python analysis notebook
- `car_data.xlsx` – CarDekho dataset

## ▶️ How to Use

1. Download or clone this repository.
2. Open `CarDekho_Car_Market_Analysis.ipynb` in Google Colab or Jupyter Notebook.
3. Keep `car_data.xlsx` in the same working directory.
4. Run the notebook cells to reproduce the analysis and visualizations.
